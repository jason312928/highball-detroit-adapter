# 复现审查

[English](../reproduction.md)

v0.3.0-preview.1 完整包补齐了当前普通游玩成功反馈所用的设置。按 [安装、启动与恢复](usage.md) 顺序执行即可。旧 v0.2.0-preview.1 包缺少独立编译器准备和完整缓存步骤，只改 README 无法复现当前流程。

| 实际组件 | 公开流程如何复现 |
|---|---|
| Highball 0.10.22 / CrossOver r28、Rosetta x86_64 | 安装前核对版本、原引擎指纹和架构，独立引擎保留这份 Wine 构建 |
| Microsoft x64 C++ 运行库 | 前置要求及 msvcp140、mfc140、vcruntime140 的 PE 预检；参考版本及哈希在 source-lock.json，不分发 Microsoft DLL |
| 独立引擎、环境和游戏 | install.sh 创建带所有权标记的副本，保留原 EXE 和原缓存，仅将新副本的首次缓存改名 |
| 严格接口 MoltenVK 变体 | 完整包包含同一固定版本 dylib，检查 SHA-256 和架构，不伪造顶点输入 |
| XAudio2 错误传递 | 完整包包含对应 x86_64 DLL 及事务式音频安装器，提供音频源码和补丁 |
| 压缩算法 3、并行编译 1 | 安装器在独立引擎及环境中设置 |
| 无需完整 Xcode 的编译器 | prepare-metal.sh 从 Apple 下载 17A324，检查归档和编译器哈希、Apple 签名，独立安装；支持 dry-run、复用、失败清理和归档回滚 |
| 游戏首次编译 | 用户从 Highball 原生入口启动一次，等待完成，退出游戏及独立 Steam |
| 持久 Metal 缓存 | compile-cache.sh 保留元数据中的数学和位置不变性选项，原子写入 .metallib，跳过已有较新输出，以后不清缓存 |
| 正常启动 | 游戏页面 → Game settings → 在 Detroit Isolated 旁点一次 Play there，以后主 Play 按钮记住环境 |
| 图形及输入 | 不要求修改图形设置、游戏 EXE 或景深；以后需要的对比单独进行 |
| 卸载 | 先归档私有工具，再恢复音频，最后归档独立引擎、环境及游戏，保留共享安装 |

## 证据与边界

参考缓存有 28,635 份二进制，全部被原生 Metal 接受；复跑新增 0、跳过全部 28,635。之后普通游玩反馈正常，不再重复长时间编译；对应游戏日志记录加载了独立 MoltenVK。这些是不同的证据来源，没有用成功构建推断游戏成功。

发布包中的工具准备脚本也在独立空目录中使用已校验的 Apple 归档真实执行过，包含签名验证、重复安装和回滚。自动化测试使用合成引擎、游戏、运行库，不启动 Wine 或游戏。发布包检查覆盖实际下载命令、哈希、解包、真实 Metal 编译及加载、脚本 dry-run。

这**不等于**在重置后的 Mac 上完整安装游戏，或覆盖所有 Apple GPU。Highball / 引擎更新需要重新审查；新场景、设置变化、不同 GPU 或软件更新可能产生额外着色器，首次数量与启动耗时也可能不同。长时间游玩、所有场景的画面/输入覆盖、实际音频设备重连仍未验证。

公开包不包含 Apple 工具、Microsoft 运行库、Steam 凭据、存档、游戏文件、生成的着色器、原始运行日志或机器快照。每份安装在本机生成 GPU 缓存；工具链锁中的 Apple 元数据是公开分发信息。
